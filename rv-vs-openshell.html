The gap RV owns. What it takes to get a first block.

curl -fsSL https://rykanv.com/install | sh
rv setup # wires 8 hosts it finds

# OpenShell — platform, then policy
curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh
# + Docker/Podman, gateway up, image pull, sandbox create, policy write…
openshell sandbox create --name demo

Where each stings

Harsh, from the repos themselves.

OpenShell pays in weight

  • Container tax on Mac (Docker Desktop) and every run
  • 0.1.x: Experimental APIs may break in a patch
  • ~35 crates + gateway ops to audit and run
  • Telemetry on unless you opt out

RV pays in guarantees

  • Hook skipped = no guard; bypass by design
  • Runtime audit: NOT SATISFIED, no Linux launch
  • Secrets stripped, never endpoint-bound like providers
  • Analytics on; setup prints no notice
Verdict: OpenShell 82 — RV 71.

For fleets, OpenShell: real boundary, verification, K8s, credential brokering. For your Mac tonight, RV: one curl and your agent stops deleting trees. Install RV today; graduate to OpenShell when you outgrow one machine.
