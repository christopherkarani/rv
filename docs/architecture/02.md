## Strangler

Keep the hook door. Insert IR and hard policy in front of packs.

```
HostCodec → ProposedAction.shell → analyze → HardPolicyEngine
                ↘ evaluate() on .unknown or as AND-deny
         → HardPolicyDecision
              ask + Ask-capable host → ApprovalBridge.hostNative
              reviewEligible → ActionReviewer (after host Ask exists)
              ask + other host → v1 unlock (TTY grant / deny), not silent allow
```

Packs are **fallback**, not the product model. **Host Ask comes before Auto-review.** AI runs only on `.reviewEligible`, and only after that host already has a working Ask path. Foundation Models stay out of RVDomain / RVEngine / RVPolicy.

### Host Ask

Ask-capable (0.2): **Pi, OpenCode, Claude, Hermes**. `ApprovalContinuation.hostNative` (or resume/defer the host already supports). Hard policy emits `.ask`; the host pauses; Allow once / Deny resolve through RV.

Not Ask-capable in this slice: **Grok** (v1 codec stays deny-or-TTY). **Codex** and **Cursor** are not in the Ask set until named.

Hermes is host-only (no Ask). Do not bolt AFM onto the missing pause path.

v1 `PLAN.md` still has no host Ask. That lock is the hook-guard. This overlay replaces it for 0.2.

## Types (RVDomain)

Closed world = enum. Open world = protocol at RVService only.

```swift
enum ProposedAction { case shell(ShellAction) }   // fs/net/mcp reserved, unused
struct ShellAction { command, cwd, host, session, fingerprint }
enum SemanticAnalysis { case git, filesystem, wrapper(inner:), unknown }
enum HardPolicyDecision { case allow, ask, deny(Deny), reviewEligible }
enum PolicyPredicate { /* typed AST, not regex */ }
enum ApprovalDecision { case allowOnce, createRule(PolicyDraft), deny }
```

Newtypes: `ActionFingerprint`, `SessionID`, `ApprovalID`, `RepositoryRoot`.
Grant key is fingerprint + session + cwd. `matchingView` remains the pack-fallback key.

Protocols (service edge, `any` ok): `ActionReviewer`, `ApprovalBridge`.
Keep `HostCodec`. Analyzers are concrete functions — Git/FS are a closed set.

`HardPolicyDecision.reviewEligible` is a kind of Ask, not Allow. A reviewer `allow` cannot type-check into `.deny`.
