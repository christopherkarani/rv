Sandboxed runtime for contained agents

rv opencode / rv workspace run attach to a persistent per-project host under deny-default Seatbelt. Linux refuses to launch rather than weaken it.

host · owns process group + volume
workspace host · persistent per project · fresh volume kills hard-link escapes
seatbelt · deny-default · children inherit
$ opencode run '…'  ·  HOME + PATH sanitized · secrets stripped

ALLOWED

  • workspace read + write
  • system read to execute
  • public HTTPS via RV proxy
  • loopback servers

DENIED

  • direct public / LAN / metadata
  • host unix sockets
  • outside signals · Mach · Keychain
  • hard links off-volume
◉  close runtime or workspace → owned process group killed · sandbox init failure → no fallback
