# H4: `rv pause 10m`, with a seatbelt

v3 Everyday Magic, "Pause, with a seatbelt." The owner, at a terminal,
passes the owner check. Every host is then watched instead of blocked for
up to an hour, and rv comes back on its own. Stacked on F3, and shares its
`GuardWindow`.

## Commands

| Command | What it does |
| --- | --- |
| `rv pause <10m\|30m\|1h>` | Pause. Durations are whole minutes (`m`/`min`) or hours (`h`), from 1 minute to 1 hour. Anything else is a usage error. |
| `rv pause [--json]` | Show status. Asks nothing and changes nothing. |
| `rv pause --end` | Come back now. This tightens, so it needs no check. `--end` with a duration is a usage error. |

## Who can pause

- **Without a terminal (any agent): refused.** No prompt is shown and nothing is written. Exit 77, stderr:
  `rv pause needs you at your terminal with Touch ID or your password; an agent can't pause rv`
- **An agent with a pty** reaches the owner check and cannot pass it. Exit 77:
  `rv pause failed: device-owner authentication required; rv was not paused`
- **Refused before any prompt:**
  - the organization gate (exit 77): `rv pause failed: organization policy keeps rv guarding this Mac`
  - an unreadable `config.json` (`EX_DATAERR`)
  - a non-installed copy of rv (`EX_USAGE`)
- **SelfProtectionGuard:** `rv pause <duration>` now counts as a weakening command, so an agent's shell call to it is denied by the hook. Bare `rv pause`, `--json` and `--end` stay allowed.

## Output

Pause:

```
◐ Paused until 14:22.
  still stopped   rm -rf ~ and /, rv's own files
  rv comes back on its own. To come back now:
→ rv pause --end
```

Status while paused (this countdown is also the first line of `rv host list`):

```
◐ Paused until 14:22 · 8 min left
  rv comes back on its own. To come back now:
→ rv pause --end
```

`rv pause --json`: `{"paused":true,"schema":"rv.pause.v1","until":"2025-11-27T14:22:00Z"}`.
Once the pause is over it reads `{"paused":false,"schema":"rv.pause.v1"}`.
`rv host list --json` adds `paused_until`.

After it ends, `◆ rv is back. It was paused until 14:22.`. With no pause:

```
◆ rv is guarding.
  To pause it for ten minutes, you type:
→ rv pause 10m
```

`--end` prints `✓ ◆ rv is back.` (or `◆ rv is guarding.` if nothing was paused).

## Storage and resolution

`guard.pause` = `{"from": <unix s>, "until": <unix s>}`, written after the
owner answers, so a slow prompt does not use up any of the pause. It is
audited as a loosening, with the owner-check method as the authorization.

The ladder is `RV_GUARD_MODE=enforce` > open pause (every host observes) >
open F3 temporary block > `guard.hosts` > `guard.mode` > enforce. A window
longer than an hour, or a clock set back before `from`, reads as closed, so
a pause can never outlast an hour. Ending needs no write and no rvd.
`machineMode` and `rv host list`'s `guard` field show the stored posture,
not the pause. Observe still keeps rv's own protection (ObserveFloor).

## Known gap

The C hook's daemon-down fallback ignores `guard.pause` and keeps
enforcing. That fails toward stricter. It is recorded in the CHANGELOG.
